## Contributing to Documentation

When updating documentation:

1. **Keep it Current**: Ensure all documentation reflects the current state of the project
2. **Be Comprehensive**: Include examples, screenshots, and step-by-step instructions
3. **Follow Style**: Use consistent formatting, headings, and language
4. **Test Instructions**: Verify all setup and configuration instructions work
5. **Update Screenshots**: Keep visual documentation up-to-date with UI changes

## Documentation Standards

- **Markdown Format**: Use GitHub-flavored markdown
- **Code Examples**: Include working, tested code snippets
- **Visual Aids**: Use screenshots, diagrams, and tables where helpful
- **Accessibility**: Ensure documentation is readable and navigable
- **Version Control**: Document version-specific changes and migration requirements
